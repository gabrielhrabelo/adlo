# ADLO Web

Frontend inicial do ADLO, feito com React, TypeScript e Vite. Nesta etapa, somente o quadro Kanban está implementado; Clientes e Agendamento aparecem na navegação como recursos em breve.

## Desenvolvimento

Requer Node.js e pnpm instalados.

```bash
cd web
pnpm install
pnpm dev
```

Os cartões e indicadores atuais são demonstrativos e ficam apenas no estado local da página. A integração com a API será feita em uma etapa posterior.

## Build

```bash
pnpm build
pnpm preview
```
